# Decisions

Accepted decisions for this project. Follow them. If a task needs a different choice, stop and say so, or propose a new decision that supersedes the old one. Don't work around them.

Generated by `devkit-decisions index` from the records in this folder. Don't edit it by hand.

- [0003: Render arrows as SVG elements](0003-render-arrows-as-svg-elements.md): Each arrow is drawn as SVG DOM elements tagged with `data-id` (a visible path, a head, and a transparent hit path), and the game does not use canvas drawing.
- [0006: Levels allow ten colour regions and a board background](0006-levels-allow-ten-colour-regions-and-a-board-background.md): A level is `{ name, mask: string[], seed, palette?, background? }`, where mask characters are `.`, `0`–`9` (region index into `palette`) or `#` (alias of `0`), `background` is `'light'` or `'dark'`, and boards are always produced by `generate(mask, seed)` using only the seeded RNG, never stored or hand-placed.
- [0007: Board input picks arrows by distance and commits on release](0007-board-input-picks-arrows-by-distance-and-commits-on-release.md): Board taps resolve to an arrow with the pure `pickArrow(board, point, radius)` and commit only on pointer release (never on press or on the DOM click target), and the transparent hit paths are used only for cursor styling.
- [0008: DOM code in main, home, render, editor and the esteira view only](0008-dom-code-in-main-home-render-editor-and-the-esteira-view-onl.md): The app uses Vite + TypeScript + Vitest with no UI framework, and only `src/main.ts`, `src/home.ts`, `src/render.ts`, `src/editor.ts` and `src/esteira/view.ts` may touch the DOM; every other module, including `src/esteira/level.ts` and `src/esteira/sim.ts`, is pure.
- [0009: Esteira levels are derived at runtime from photo levels](0009-esteira-levels-are-derived-at-runtime-from-photo-levels.md): Esteira de Cores levels are built at runtime from the photo levels in `LEVELS` by `esteiraLevels()` (never stored as separate data), and every built level must be winnable by `greedyWins`, reseeding until it is.
