# Decisions

Accepted decisions for this project. Follow them. If a task needs a different choice, stop and say so, or propose a new decision that supersedes the old one. Don't work around them.

Generated by `devkit-decisions index` from the records in this folder. Don't edit it by hand.

- [0001: Vite, TypeScript and Vitest with pure logic modules](0001-vite-typescript-and-vitest-with-pure-logic-modules.md): The app uses Vite + TypeScript + Vitest with no UI framework, and only `src/render.ts` and `src/main.ts` may touch the DOM; `model`, `generate`, `solve` and `game` are pure functions.
- [0002: Levels are ASCII masks plus a seed](0002-levels-are-ascii-masks-plus-a-seed.md): A level is `{ name, mask: string[], seed }` with `#` for playable cells and `.` for empty ones, and boards are always produced by `generate(mask, seed)` using only the seeded RNG, never stored or hand-placed.
- [0003: Render arrows as SVG elements](0003-render-arrows-as-svg-elements.md): Each arrow is drawn as SVG DOM elements tagged with `data-id` (a visible path, a head, and a transparent hit path), and the game does not use canvas drawing.
