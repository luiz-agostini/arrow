# Decisions

Accepted decisions for this project. Follow them. If a task needs a different choice, stop and say so, or propose a new decision that supersedes the old one. Don't work around them.

Generated by `devkit-decisions index` from the records in this folder. Don't edit it by hand.

- [0003: Render arrows as SVG elements](0003-render-arrows-as-svg-elements.md): Each arrow is drawn as SVG DOM elements tagged with `data-id` (a visible path, a head, and a transparent hit path), and the game does not use canvas drawing.
- [0004: DOM code in render, editor and main only](0004-dom-code-in-render-editor-and-main-only.md): The app uses Vite + TypeScript + Vitest with no UI framework, and only `src/render.ts`, `src/editor.ts` and `src/main.ts` may touch the DOM; `model`, `generate`, `solve`, `game`, `picture` and `colors` are pure functions.
- [0005: Levels are region masks with an optional palette](0005-levels-are-region-masks-with-an-optional-palette.md): A level is `{ name, mask: string[], seed, palette? }`, where mask characters are `.` (empty), `0`–`5` (region index into `palette`) or `#` (alias of `0`), and boards are always produced by `generate(mask, seed)` using only the seeded RNG, never stored or hand-placed.
